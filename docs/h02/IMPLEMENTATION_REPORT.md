## F. Architecture

Catalog is a vertical slice: shared schemas/types, authoritative SQL plus Drizzle schema, explicit transactional commands, thin Fastify routes and capability-driven React workspaces. Mutations use `operationId`, payload fingerprints, saved success/failure outcomes and account-scoped own-operation recovery. Commands lock Category before Service where both participate, preventing Publish/Category-archive races. Terms are append-only and the Service points to the current version.

No Product Truth or Plan deviation was required. Oxlint was added because CURRENT had no lint facility and the TypeScript 7 toolchain is not supported by typescript-eslint/ESLint at certification time.
